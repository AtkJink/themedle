# Themedle — Thematic Wordle & Deduction Game

An AI-powered deduction and word game built with **Next.js**, **React**, **Tailwind CSS**, and **Google Gemini API**.

---

## 🎮 How to Play

### 1. Theme Detective Mode (Core Game)
- **Solve Sequential Words**: Guess a series of hidden words (configurable 3 to 6 words) of varying lengths (e.g. 4, 6, 5, 7 letters).
- **Find the Pattern**: Each solved word is a clue. All words share a hidden connecting theme generated by AI (e.g. *Space Exploration*, *Baking & Confections*, *Medieval Castle*).
- **The Grand Deduction**: Once all words are revealed, you enter the **Theme Deduction** stage to guess what ties them together. The AI semantically grades your answer (accepting synonyms and broader/narrower answers).

### 2. Daily Classic Wordle
- Guess the daily 5-letter word in 6 attempts.
- A new puzzle is seeded every day at midnight UTC, identical for players worldwide.
- Track win rate, streaks, and guess distribution in local browser storage (no account needed).
- Share results with the classic emoji grid (`🟩🟨⬛`).

## 🚀 Running Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **(Optional) Add a Gemini API Key**:
   Create a `.env.local` file:
   ```env
   GEMINI_API_KEY=your_free_gemini_api_key_here
   ```
   > *Note: If no API key is set, the game runs smoothly using built-in curated theme puzzles and client-side heuristics.*

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Free Deployment (Always Accessible)

Because this is a standard Next.js App Router project, you can deploy it for free in 1 click:

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "feat: initial commit of Themedle"
   git remote add origin https://github.com/AtkJink/themedle.git
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com) and sign in with GitHub.
   - Click **"Add New"** > **"Project"** and import `themedle`.
   - In **Environment Variables**, add `GEMINI_API_KEY` (from [Google AI Studio](https://aistudio.google.com/app/apikey)).
   - Click **Deploy**. Vercel will build and host your game with a free `.vercel.app` domain and automatic continuous deployment on every Git push.
